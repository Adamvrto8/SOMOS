# App Tour Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A one-time, optional spotlight tour on Domov, offered on the first Domov visit after the welcome + first lesson, replayable from Profil.

**Architecture:** State lives in the existing onboarding state (`src/lib/onboarding.ts`, localStorage, device only) as a new `tour` field; pure logic in `src/lib/tour.ts`. The UI is `src/features/tour/` (offer card, overlay portal, `useTour` hook). The overlay runs on its own history entry (like SOMO's sheet) so the phone's Back closes it; targets are found by `data-tour` attributes.

**Tech Stack:** React 19 + TypeScript, react-router, Tailwind tokens, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-17-app-tour-design.md`

## Global Constraints

- UI strings Slovak (source) + English in `src/i18n/sk.ts` / `en.ts` (`en: Dictionary` must type-check); code, comments, commits English.
- No new dependency.
- Mobile first: test at 375px; max column 480px.
- Never stage `CLAUDE.md`, `poznaky.txt`, `.gitignore`, `Design/`, `test-results/` or `docs/accounts-setup.md` (Adam's own changes): stage explicit paths only.

## Deviations from the spec (decided while planning)

- Domov gets **two** steps (the "what's next" card, then streak/goal tiles) instead of one: the hero card and the tiles say different things. Steps: next, progress, somo, search, path, practice, profile (7; SOMO is skipped when its pill is not shown, which today is everyone but dev mode + signed-in, so learners see 6).
- Usage numbers reuse the existing `welcome` event with new `step` values (`tour-start`, `tour-declined`, `tour-done`) instead of a new `tour` event: the server report (`usage_report()` in `supabase/schema.sql`) already groups `welcome` by step, so **no SQL change** is needed. Skips = `tour-start` − `tour-done`.
- Eligibility: only devices that finish the welcome **after this ships** get `tour: 'pending'` (set by the welcome's last step). Devices welcomed earlier, restored accounts ("Už mám účet") and old devices never get the offer.

## Review Focus

1. Back button during the tour: must close the tour and stay on Domov, never leave the app or reopen the tour.
2. Replay from Profil (`/?tour=1`): must start once, not loop, and not leave `?tour=1` in the address (reload must not restart it).
3. The overlay must block taps and keyboard focus on the page behind (`#root` inert) and release it on every exit (Hotovo, Preskočiť, Escape, Back, unmount).
4. Bubble must stay on screen for targets at the top (hero card) and at the bottom (tab bar) at 375×800 and in a short viewport.
5. A device with `done: true` and no `tour` field (every existing user, and the Playwright default storage) must never see the offer.

```ts
import { getOnboarding, updateOnboarding, type OnboardingState } from './onboarding'
import { track } from './usage'

// The tour of the app on Domov (docs/superpowers/specs/2026-11-17-app-tour-design.md). The state is the `tour` field of
// the welcome's state: this device only, not synced, not in the backup.

/** Each stop: the `data-tour` attribute it highlights; its text is dictionary.tour.steps[id]. */
export const TOUR_STEPS = [
  { id: 'next', target: 'home-next' },
  { id: 'progress', target: 'home-progress' },
  { id: 'somo', target: 'somo' },
  { id: 'search', target: 'tab-search' },
  { id: 'path', target: 'tab-path' },
  { id: 'practice', target: 'tab-practice' },
  { id: 'profile', target: 'tab-profile' },
] as const

export type TourStep = (typeof TOUR_STEPS)[number]
export type TourStepId = TourStep['id']

/** The steps whose target is on screen now (SOMO's pill is there only for some accounts). */
export function visibleSteps(isPresent: (target: string) => boolean): TourStep[] {
  return TOUR_STEPS.filter((step) => isPresent(step.target))
}

export function shouldOfferTour(state: OnboardingState | null): boolean {
  return state?.done === true && state.tour === 'pending'
}

// Usage numbers go with the welcome's steps: the server's report already counts them (supabase/schema.sql).
export function acceptTour() {
  updateOnboarding({ tour: 'started' })
  track('welcome', { step: 'tour-start' })
}

export function declineTour() {
  updateOnboarding({ tour: 'declined' })
  track('welcome', { step: 'tour-declined' })
}

/** Hotovo on the last step. A replay from Profil changes nothing stored. */
export function finishTour() {
  if (getOnboarding()?.tour !== 'started') return
  updateOnboarding({ tour: 'finished' })
  track('welcome', { step: 'tour-done' })
}

/** Nástroje pre vývoj: the offer on Domov once more (done: true, so the welcome does not open instead). */
export function offerTourAgain() {
  updateOnboarding({ done: true, tour: 'pending' })
}

/** Where the text goes: under a target in the upper half of the screen, above one in the lower half (the tab bar). */
export function bubbleSide(target: { top: number; bottom: number }, viewportHeight: number): 'above' | 'below' {
  return (target.top + target.bottom) / 2 > viewportHeight / 2 ? 'above' : 'below'
}
```

```ts
 * The tour runs on its own history entry, like SOMO's sheet: the phone's Back closes it and stays on Domov.
 * `/?tour=1` (Profil → Zopakovať zoznámenie) starts it; the address is cleaned so a reload does not start it again.
 */
export function useTour() {
  const location = useLocation()
  const navigate = useNavigate()
  const touring = (location.state as { tour?: unknown } | null)?.tour === true
  const replay = new URLSearchParams(location.search).get('tour') === '1'
  const handled = useRef(false) // StrictMode runs the effect twice in development

  const start = useCallback(() => void navigate('/', { state: { tour: true }, preventScrollReset: true }), [navigate])

  const close = useCallback(() => {
    // Started in this session: step back to Domov. From a reloaded entry: just drop the flag.
    if (((window.history.state as { idx?: number } | null)?.idx ?? 0) > 0) void navigate(-1)
    else void navigate('/', { replace: true, preventScrollReset: true })
  }, [navigate])

  useEffect(() => {
    if (!replay || handled.current) return
    handled.current = true
    void navigate('/', { replace: true })
    void navigate('/', { state: { tour: true } })
  }, [replay, navigate])

  return { touring, start, close }
}
```

```tsx
import { useEffect, useLayoutEffect, useRef, useState } from 'react'
import { createPortal } from 'react-dom'
import { Button } from '../../components/Button'
import { useT } from '../../i18n'
import { bubbleSide, visibleSteps } from '../../lib/tour'

/** Air around the highlighted target, and the gap to the text bubble, in px. */
const PAD = 6
const GAP = 12

const find = (target: string) => document.querySelector<HTMLElement>(`[data-tour="${target}"]`)
const reducedMotion = () => window.matchMedia?.('(prefers-reduced-motion: reduce)').matches ?? false

interface TourOverlayProps {
  /** Preskočiť, Escape: the tour ends where it is. */
  onClose: () => void
  /** Hotovo on the last step. */
  onFinish: () => void
}

/**
 * The screen darkened around one highlighted part of Domov, with a short text, step after step. Rendered on <body>,
 * with the app (#root) inert meanwhile: nothing behind it can be tapped, focused or read by a screen reader.
 */
export function TourOverlay({ onClose, onFinish }: TourOverlayProps) {
  const text = useT().tour
  // Fixed when the tour starts: a step whose target is not on screen is left out.
  const [steps] = useState(() => visibleSteps((target) => find(target) !== null))
  const [index, setIndex] = useState(0)
  const [rect, setRect] = useState<DOMRect | null>(null)
  const bubble = useRef<HTMLDivElement>(null)
  const step = steps[index]
  const last = index === steps.length - 1

  useEffect(() => {
    if (!step) onClose() // nothing to show
  }, [step, onClose])

  useEffect(() => {
    const root = document.getElementById('root')
    if (!root) return
    root.inert = true
    return () => {
      root.inert = false
    }
  }, [])

  // The target into view, then followed while the page scrolls there or the screen turns.
  useLayoutEffect(() => {
    if (!step) return
    const el = find(step.target)
    if (!el) {
      setRect(null)
      return
    }
    let frame = 0
    const measure = () => {
      cancelAnimationFrame(frame)
      frame = requestAnimationFrame(() => setRect(el.getBoundingClientRect()))
    }
    el.scrollIntoView({ block: 'center', behavior: reducedMotion() ? 'auto' : 'smooth' })
    setRect(el.getBoundingClientRect())
    window.addEventListener('scroll', measure, true)
    window.addEventListener('resize', measure)
    return () => {
      cancelAnimationFrame(frame)
      window.removeEventListener('scroll', measure, true)
      window.removeEventListener('resize', measure)
    }
  }, [step])

  // Focus on the main button of each step, so Enter goes on and a screen reader reads the new text.
  useEffect(() => {
    bubble.current?.querySelector<HTMLButtonElement>('[data-primary]')?.focus({ preventScroll: true })
  }, [index])

  useEffect(() => {
    const onKey = (e: KeyboardEvent) => {
      if (e.key === 'Escape') onClose()
    }
    window.addEventListener('keydown', onKey)
    return () => window.removeEventListener('keydown', onKey)
  }, [onClose])

  if (!step) return null
  const content = text.steps[step.id]
  const side = rect ? bubbleSide(rect, window.innerHeight) : 'below'
  const place =
    side === 'below'
      ? { top: (rect ? rect.bottom : 96) + PAD + GAP }
      : { bottom: window.innerHeight - (rect ? rect.top : window.innerHeight) + PAD + GAP }

  return createPortal(
    // touch-none: a finger on the dark part does not scroll the page behind.
    <div className="fixed inset-0 z-40 touch-none">
      {rect ? (
        // The cut-out: a box over the target whose huge shadow is the dark layer.
        <div
          aria-hidden
          className="pointer-events-none fixed rounded-2xl shadow-[0_0_0_200vmax_rgb(0_0_0/0.62)] motion-safe:transition-all motion-safe:duration-300"
          style={{ top: rect.top - PAD, left: rect.left - PAD, width: rect.width + 2 * PAD, height: rect.height + 2 * PAD }}
        />
      ) : (
        <div aria-hidden className="absolute inset-0 bg-black/60" />
      )}
      <div className="fixed inset-x-0 px-4" style={place}>
        <div
          ref={bubble}
          key={step.id}
          role="dialog"
          aria-modal="true"
          aria-labelledby="tour-title"
          aria-describedby="tour-body"
          className="mx-auto max-w-[448px] rounded-card border border-line bg-surface p-5 shadow-[0_12px_40px_-12px_rgb(0_0_0/0.45)] motion-safe:animate-fade-in"
        >
          <p className="text-xs font-semibold tracking-widest text-ink-muted uppercase">{text.progress(index + 1, steps.length)}</p>
          <h2 id="tour-title" className="mt-1 font-serif text-2xl font-semibold tracking-tight">
            {content.title}
          </h2>
          <p id="tour-body" className="mt-2 text-ink-muted">
            {content.body}
          </p>
          <div className="mt-4 flex items-center gap-2">
            <button
              type="button"
              onClick={onClose}
              className="-ml-2 h-11 rounded-full px-3 text-sm font-semibold text-ink-muted transition-colors duration-150 hover:text-ink focus-visible:outline-2 focus-visible:outline-brick"
            >
              {text.skip}
            </button>
            <span className="flex-1" />
            {index > 0 && (
              <Button variant="secondary" onClick={() => setIndex(index - 1)}>
                {text.back}
              </Button>
            )}
            <Button data-primary onClick={() => (last ? onFinish() : setIndex(index + 1))}>
              {last ? text.done : text.next}
            </Button>
          </div>
        </div>
      </div>
    </div>,
    document.body,
  )
}
```
